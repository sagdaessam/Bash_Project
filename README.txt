
A Bash project that scans directories,
checks file permissions, counts extensions,
searches files and creates backups.

Files:
- auditor.sh: Main program and menu.
- lib.sh: Helper functions.
- README.txt: Project information.

How to run:

1. Give execution permission:
   chmod u+x auditor.sh lib.sh

2. Open the menu:
   ./auditor.sh sample_data

3. Run scan:
   ./auditor.sh sample_data scan

4. Run permissions:
   ./auditor.sh sample_data perms

5. Run extension report:
   ./auditor.sh sample_data ext

6. Run backup:
   ./auditor.sh sample_data backup
